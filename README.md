# ☕ AI Shop MVP — 精品咖啡館 AI 智能配單與自動報價

輕量級微電商 AI 導購與自動報價系統前端頁面（教學工作坊示範專案）。

- **前端網頁**：GitHub Pages 靜態頁面（`index.html`）
- **後端中樞**：Google Apps Script Web App（`/exec`）
- **資料庫**：Google Sheets（`Products` 與 `Orders` 分頁）
- **AI 模型**：OpenRouter · `anthropic/claude-haiku-5.5`
- **自動通知**：`GmailApp` 報價單信件 + LINE Messaging API 店家推播
